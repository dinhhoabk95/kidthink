# Bản Đồ Phân Phối Chương Trình 126 Tiết — Hành Trình 42 Tuần (CUR-J42 Lesson Map)

> **Mục tiêu:** Bản đồ phân phối toàn diện 126 bài học của chương trình dài nhất `CUR-J42` (42 tuần × 3 tiết/tuần) theo chuẩn sư phạm mầm non Việt Nam.
> **Quy tắc:** D1, D4, D7 (`docs/tasks/192-golive-preschool-pedagogy-plan.md`), `BR-LCD-01`, `BR-LFM-01..06`.
> **Cấu trúc mỗi tiết:** Đủ 3 pha (Khởi động/Khám phá → Trọng tâm/Thao tác → Luyện tập/Củng cố), ≥3 hoạt động, ≥2 kiểu hoạt động, ≥1 trò chơi số (`digital_game`).
